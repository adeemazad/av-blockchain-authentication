# Hybrid Blockchain Authentication for Autonomous Vehicles

## Overview
A secure vehicle-to-vehicle communication system using a hybrid 
reputation-based blockchain authentication model, neural network 
anomaly detection, and Hyperledger Fabric.

## Results
- 3x lower latency vs baseline
- 85% reduction in blockchain transaction costs
- O(log n) authentication scalability across 100–1,000 vehicles

## Technologies Used
Hyperledger Fabric, LabVIEW, Python, Neural Networks
